# AQIL — Architecture Decision Records (Summary)
**Status: accepted for v2 baseline, subject to explicit future ADR amendments.**

| ADR | Decision | Why | Revisit when |
|---|---|---|---|
| 001 | Next.js App Router + typed modular monolith | one coherent PWA, accessible UI and SSR | separate teams/interfaces or measurable performance bottlenecks |
| 002 | Scheduled Python research worker, no FastAPI in v1 | quant tooling without redundant service | interactive Python features need a separately scalable API |
| 003 | PostgreSQL authoritative store, Supabase Auth/RLS | relational audit data and multi-tenant readiness | measured demand for analytics warehouse/graph/search |
| 004 | Typed versioned contracts and immutable research origins | cross-stack reproducibility and forward compatibility | never revoke, only evolve version |
| 005 | Deterministic numeric methods; LLM synthesis bounded | reproducibility and source integrity | only change with evaluation and new ADR |
| 006 | Evidence verification and human editorial gate | cannot guarantee LLM/source truth; contain blast radius | limited low-risk template review automation proven safe |
| 007 | Researcher/challenger/champion role separation | prevent post-hoc overfit and silent self-rewriting | never revoke; implementation may evolve |
| 008 | ETF canonical identity by legal class + listing | avoid ticker/share class/currency errors | never revoke |
| 009 | Source and data rights recorded per permitted action | private/public/commercial licences differ | never revoke |
| 010 | Event journal, cashflow matched benchmark, independent lab ledger | accurate wealth and credible evidence | never revoke; implementations evolve |
| 011 | No trading, leverage or public personal reallocation advice | risk, philosophy and current compliance boundary | separately scoped legal/commercial mandate |
| 012 | Daily reading/editorial from same reviewed research object | coherent novice/expert experiences | if research content models genuinely diverge |
| 013 | Semantic tokens and Aptos-first white/navy/gold UI | consistent multi-year design | central design-system ADR |
| 014 | Private use → free signups → paid plans, grandfather entitlements | user mission + commercial optionality | legal/economics gate |
| 015 | Shared global research, private portfolio isolation | economic serving cost and privacy | later scale needs differentiated research cohorts |
| 016 | Optional anonymous reading and optional private wealth | inclusive product, consent minimisation | privacy UX evidence |
| 017 | No graph/vector DB at first | relational representation adequate for MVP | measured complexity/quality improvement |
| 018 | CI, migrations, security fixtures and restore drill from day one | prevent rebuild and data loss | never revoke |
| 019 | Server-side Supabase SSR session authority; doctrine in AUTH_AND_SESSION_DOCTRINE.md | prevent auth drift, refresh races and PWA logout bugs | only via ADR if identity model changes |
| 020 | Any verified Google account may open Aqil. Identity is `auth.users.id`. The founder allow-list and `access_grants` gate are superseded (18 October 2026) and must not be reintroduced for ordinary access | one user should sign in without an operator step; RLS still isolates private rows | a future explicit sharing or admin role, by a new ADR |
| 021 | Saxo is authoritative for Saxo positions and account values. Aqil normalises that source. Manual entry does not recreate the same brokerage account. Simulation is stored apart from live wealth and is never presented as live | one portfolio per real account; no synthetic rows in live wealth | a second broker needs its own source, not a copy of the Saxo snapshot |
| 022 | Ingest Saxo as snapshots first. Transactions, benchmarks, original-plan counterfactuals, model portfolios and long-term plans are future records and stay separate from observed values | the current read can be truthful without a speculative warehouse | historical events are added when the broker or statements actually support them |
| 023 | Keep observed broker values distinct from calculated metrics. Account-value change is not investment return. Broker time-weighted return is not that change. Price result, currency result and costs are separate and are omitted when the response did not include them | labels match the field that was retrieved | an independently calculated return needs its own method version and fixtures |
| 024 | Production broker connect requires encrypted, owner-scoped token storage and RLS. Gitignored local files are development only. The live Saxo credential can trade at Saxo; Aqil allow-lists read-only GETs and must not trade. A trading-disabled Saxo application is required before hosted tokens are kept | localhost must not be described as a production broker connection | hosted persistence after migration tests and an explicit founder approval |
| 025 | `public.wealth_allocation_targets` in `supabase/migrations/20261018210000_my_wealth.sql` is the single intended policy store. The gitignored file `apps/web/.local/investment-policy/{userId}.json` is development-only and is not a second permanent system (24 October 2026). The save path was not switched, founder financial data was not migrated, and the hosted wealth migration was not applied | one authoritative allocation policy, with the local file unable to diverge in production | switch the save path only after the hosted migration is approved and tested |
| 026 | Macro events and the AI infrastructure theme are four append-only `research` tables, registered manually, with `publication_allowed` false and no strength or gauge. They extend Intelligence and are not a new destination. Federal Register notice 2026-20510 is stored from operator-supplied fields because govinfo `automated_access` remains unknown. The Federal Reserve row records publication only and stays off Today. The SEC theme is not stored while `AQIL_SEC_USER_AGENT` is unset. AQ-035 is still not started, and institutional capital is not part of this slice (24 October 2026). The migration is local only | one evidence record can be shown without turning a notice or a filing into an investment instruction | a later source or a schedule needs its own rights row and must not start AQ-035 by renaming this slice |
| 027 | From 25 October 2026 the immediate research priority is methodology-first Macro Intelligence, specified in `docs/macro/00_METHODOLOGY_PROGRAMME.md`. The methodology determines which series are acquired. Economic conclusions are produced by implemented, versioned calculations. A language model may help research, code, and document those calculations. It does not decide whether an economy is strengthening, deteriorating, or in recession. The first build is an engineering pilot of the monthly Bry–Boschan procedure on stored US industrial production. That pilot is not the first strategic intelligence capability. The first strategic capability is a specified Stock–Watson dynamic factor model, and only after its data contract is verified. Harding–Pagan quarterly BBQ is not applied to monthly observations. The NBER chronology is an external diagnostic, not a numerical acceptance test. ETF Intelligence, My Wealth, Forward Intelligence, and publication controls remain. This extends ADR 005 and ADR 006. It supersedes the 18 October 2026 sentence in `docs/03_RESEARCH_ENGINE_AND_METHODS.md` that new macro-method work waits on a My Wealth or Deploy Capital decision, and the roadmap sentence that forbids another macro collection wave as a bar on this programme | one repeatable path from a published method to a monitored result, without a generic modelling platform and without an indiscriminate data collection wave | a later ADR if a language model is ever proposed as the source of an economic conclusion, or if model promotion rules in ADR 005 change |
| 028 | Unpublished research reads require `app_metadata.aqil_research = founder` on `auth.users.id`. Ordinary Google sign-in still opens the application, including Conditions. ADR 020 is unchanged for that ordinary access. The claim is not an email comparison, and `authenticated` receives no new database privilege. `publication_allowed` stays false (2 November 2026) | the founder required founder-authorised access for unpublished research after any signed-in account could read it | a later sharing role needs a new ADR |
| 029 | Long-horizon traceability extends the existing `research` schema with append-only hypothesis, experiment, execution, evidence, and claim rows. Category C is price-only simulator research and is not macroeconomic investment intelligence. Candidate catalogue rows are not executions. `publication_allowed` stays false. Migration `20261103170000` is local only (3 November 2026) | `research.research_runs`, prospective assessments, and the unpublished parameter-version file cannot carry that contract without breaking their checks or inventing a macro run | a category A experiment needs a vintage that covers that method's own inputs, and publication would need a new ADR |
| 030 | A historical state atlas stores decision anchors, state observations, and later outcome measures as separate append-only rows. The research matrix is a view at anchor grain. Latest-revised economic features are retrospective and are not decision inputs. Only the stored BEA real GDP growth vintage is point-in-time, and only at its own printed release date. Registered methods stay an inventory until a vintage covers that method's own inputs. Category C cannot be statistically supported, economically useful, or forward-validated. `no_incremental_information` is an allowed non-promotion status. `publication_allowed` stays false. Migration `20261104120000` is local only (4 November 2026) | one anchor must be able to show what was knowable then and what happened later, without copying a forward return into a state or inventing a release date for a latest-revised series | a new outcome family is `EVT-DEF-002`; a method-state series needs its own vintage and `vintage_gate.py`; a portfolio test needs a later validated condition and is still not a holdout on this inspected history |
| 031 | `ETF-PROT-001` scores VWRA, EIMI, and their matched excess from the shared atlas. `EVT-DEF-002` adds sustained decline, persistent bear, failed recovery, trend reversal, and volatility transition, with thresholds mirrored from `EVT-DEF-001` before either dossier was scored. Logistic, probit, and regularized searches are refusal rows. Methods stay an inventory. The promotion rule requires a point-in-time input, an uninspected evaluation period, and incremental information over the price-only control, so this inspected history returns `no_policy_registered`. `publication_allowed` stays false. Migration `20261104183000` is local only (4 November 2026) | one frozen grid can be repeated for a later listing without fitting a model to VWRA after the fact, and without treating an emerging-market overweight as a separate diversifier | a later listing needs the same grid and a new execution; a portfolio path still needs its own validated condition and is not a holdout on this history |
| 032 | VWRA discovery replays the 26 registered methods on stored latest-revised inputs and joins a number to a month-end only when that method's period end is on or before the anchor. Full-sample filters, ex-post smoothers, and confirmation delays are `retrospective_reconstruction`. Census methods with no stored rows stay unavailable. Downside volatility and trend persistence use closes on or before the anchor. A later return is not a state. Findings stay descriptive or retrospective_exploratory. Logistic and probit stay `not_estimable_effective_sample` when the frozen floors of 60 decision points and 15 non-overlapping 126-session keeps are missed. The inflation-deceleration then positive 63-session momentum sequence was frozen before the score and is not an executable strategy. A Benjamini-Hochberg flag cannot promote a claim. Dossier comparisons are counted apart from the one portfolio simulation. `publication_allowed` stays false. Migration `20261104210000` is local only (4 November 2026). The record is `docs/research/vwra-discovery/README.md` | the stored methods can be read as numbers on VWRA without calling a retrospective replay a point-in-time signal or a portfolio test | the same battery on EIMI is a later execution; a point-in-time method still needs a vintage of its own inputs |
| 033 | EIMI uses the same discovery package, parameterised by symbol, rather than a second registry. The method census is read from the stored VWRA-DISCOVERY-001 points and does not delete them. Component counts are not distinct dates. Point-in-time methodology output stays zero. Census methods stay unavailable and inflation autoregression stays its stored failure. The matched excess is the EIMI session-step return minus the VWRA session-step return on month-ends at or after 2019-07-25 within five days. A pairwise divergence of 0.10 excess over 126 sessions was mirrored from the existing 0.10 magnitude before any EIMI score. EVT-DEF-001 and EVT-DEF-002 are not edited. The stored sequence stays strictly positive and is not retuned to the 0.05 binary. Logistic and probit use the same floors of 60 and 15. The price-only portfolio, when the simulator can represent both US-dollar listings, uses the category C contribution, cost, and start date, and a higher terminal wealth stays inconclusive. `publication_allowed` stays false. Migration `20261105120000` is local only (5 November 2026). The record is `docs/research/eimi-discovery/README.md` | one frozen battery can be repeated for the emerging-market overweight without fitting a threshold after seeing EIMI, and without treating that overweight as an independent diversifier or a total-return study | a point-in-time method still needs a vintage of its own inputs; a currency comparison needs stored foreign-exchange observations |
| 034 | CNDX uses the same discovery package, parameterised by symbol. The return audit records split-adjusted US-dollar XLON closes for CNDX and VWRA. NAV, fund returns, benchmark returns, and foreign exchange are absent, so an economic investment claim stays blocked. `LH-C-017` version 2 quotes the stored EIMI casebook counts. `LH-V-017`, `CMP-F-017`, and the casebook counts are not rewritten. The CNDX thresholds, including the strictly positive sequence and the 0.10 excess, were frozen before the score. The matched excess is the CNDX session-step return minus the VWRA session-step return. An excess partial survives `VWRA:trailing_return_252` only when its absolute partial Spearman is strictly greater than the absolute Spearman of `CNDX:relative_performance_vs_vwra_252`. Otherwise the relative result is structural exposure or price momentum. The price-only portfolio calls the simulator paths that already exist and leaves bounded VWRA-to-CNDX rotation unimplemented. A higher terminal wealth stays inconclusive. `publication_allowed` stays false. Migration `20261105180000` is local only (5 November 2026). The record is `docs/research/cndx-discovery/README.md` | one frozen battery can be repeated for the stored CNDX listing without fitting a threshold after seeing CNDX, and without treating a split-adjusted close as a total return or a point-in-time signal | a rights-cleared total-return series already in the repository, or a vintage that covers one registered method's own inputs; CSPX is the next listing and is not executed here |
